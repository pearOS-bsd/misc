# Default desktop pictures

`dark-mode.jpg` and `light-mode.jpg` come from the pearOS settings repository (https://github.com/pearOS-archlinux/pearos-settings, `usr/share/extras/wallpapers/Default/`); the author of the default pictures (`def_dark/light.png` in that repository's COPYRIGHT.txt) is Nathan <clockyshipper99@gmail.com>.

They are installed where the Mac keeps its own desktop pictures, `/System/Library/Desktop Pictures/`, and the Finder uses the one that fits the appearance (dark or light) when no picture was chosen (preference `DesktopPicture`).
