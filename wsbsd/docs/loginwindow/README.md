# loginwindow on the Mac, and what wsbsd's login window takes from it

Measured / decompiled on the owner's Mac (macOS 27), 2026-10-29, with REA (Ghidra) and the Objective-C runtime.

- `/System/Library/CoreServices/loginwindow.app/Contents/MacOS/loginwindow` is only the session logic (1.5 MB, 788 imported classes): `LFSMSession` / `LFSessionOwnerListener` (the state machine of the login session, from `login.framework`), `SFAuthorization`, `ODSession` (OpenDirectory), `SLSessionOwner` (SkyLight session), `UMUserManager`, `ADMLoginPrefs`, Platform SSO, FileVault unlock users (`LUIFVUnlockUser`).
- **The user interface is `LoginUIKit.framework`** (`LUI2*` classes, AppKit: `NSView`, `NSVisualEffectView`, `NSStackView`, `NSCollectionView`; 183 classes): `LUI2UIController`, `LUI2Window`, `LUI2UserCollectionViewController` with the layouts (`LUI2UserGridLayout`, `ListLayout`, `StackLayout`, `PeekabooLayout`), `LUI2UserViewController` / `LUI2UserPictureView`, `LUI2SecureTextField(+Cell+ViewController)`, `LUI2BigTimeViewController` / `LUI2BigTimeTextField`, `LUI2DateViewController`, `LUI2BatteryViewController`, `LUI2PowerViewController`, `LUI2WiFiViewController`, `LUI2AuthHintViewController`, `LUI2PasswordHintViewController`, `LUI2WallpaperController`, `LUI2TextFieldBackgroundView`, `LUI2CircleButtonView`, `LUI2GlyphButton`, `LUI2VisualEffectView`.
- Files here: `LoginUIKit.objc.txt` (every class, ivar, property and method with its address, 5558 lines, from `tools/objc_dump.m`), `LoginUIKit.control-specs.txt` (the buttons: login = `arrow.right.circle` 22 x 22, cancel `xmark.circle` 17, shutdown `power` 17, restart `restart.circle` 17, sleep `sleep` 17, switch user `person.crop.circle` 17, password hint `questionmark.circle` 22, ...), `LoginUIKit.class-constants.txt` (user picture diameter 70, shadows: primary radius 1 opacity 1, secondary radius 3 opacity 0.5).
- The loginwindow of the real Mac cannot be captured without logging out, but its views can be built in a test process from LoginUIKit and read (see the probe in this commit's message); next steps: instantiate `LUI2UserViewController` / `LUI2BigTimeViewController` / `LUI2PasswordViewController` offscreen, read their frames and fonts, and port the logic of `LUI2UIController` (state: choose user, password, wrong password shake, hint, shutdown / restart / sleep buttons, battery, Wi-Fi menu) to `loginwindow/LoginWindow.m`.
- The current `loginwindow/` follows the pearOS design (pkgbuilds kscreenlocker pearOS-dark), as the owner asked on 2026-10-29; the Apple LoginUIKit data is the reference for what the real one does (behaviours, the button set, the 70 pt picture).
