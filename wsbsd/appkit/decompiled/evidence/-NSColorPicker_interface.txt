/* measured (real AppKit, macOS 27 26A5416b): NSColorPicker is the abstract base
   adapter for NSColorPanel picker plug-ins (adopts NSColorPickingDefault).
   initWithPickerMask:colorPanel: stores both; colorPanel getter returns it;
   buttonToolTip defaults to the class name ("NSColorPicker"); setMode:/attach-
   /detachColorList:/alphaControlAddedOrRemoved:/viewSizeChanged: are no-ops in
   the base. minContentSize/provideNewButtonImage call the abstract
   provideNewView: and THROW on the raw base = subclass responsibility (stage2). */
