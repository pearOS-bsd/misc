# The window tab group (window.tabGroup). Public: identifier, windows (readonly), selectedWindow, overviewVisible, tabBarVisible(readonly). addWindow:/insertWindow:atIndex:/removeWindow: and allowsDraggingTabs/allowsDetachingTabs are SPI (not dot-accessible in a standalone probe; drag/detach defaults assumed YES per NSWindow tabbing docs, could not be measured without a live tabbed window). tabBarVisible == (windows.count>1 || shouldShowTabBarWithOneItem). The tab-bar UI, overview animation, plusTab and window-server tabbing are stage2; the window-list + selection model is reproduced here.
