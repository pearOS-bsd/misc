/* NSTextContentStorage lives in UIFoundation (re-exported by AppKit); concrete
   NSTextContentManager backed by an NSAttributedString/NSTextStorage. Measured
   (AppKit runtime, macOS 27 26A5416b): -init => empty attributedString,
   documentRange "0...0"; setting a 5-char string gives documentRange of length 5;
   offsetFromLocation:toLocation: / locationFromLocation:withOffset: do integer
   offset arithmetic; textElementsForRange: splits the text into one
   NSTextParagraph per paragraph ("ab\ncd" -> 2 NSTextParagraph elements).
   Locations are integer offsets (NSCountableTextRange internally). NSTextStorage
   live observation + attachment handling = stage2. */
